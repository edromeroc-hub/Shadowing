Política de Privacidade do ShadowingAI

Última atualização: 12 de setembro de 2026.

Dados armazenados no dispositivo

O ShadowingAI armazena localmente no dispositivo informações de perfil, histórico de estudos, progresso, preferências, vídeos baixados e a chave de API fornecida pelo próprio usuário. A chave de API é protegida pelo armazenamento seguro do sistema.

Microfone

O acesso ao microfone é usado somente quando o usuário inicia exercícios de pronúncia ou escuta. As gravações são processadas para oferecer a atividade solicitada e não são vendidas.

Serviços externos

O aplicativo pode se comunicar com o YouTube para obter e reproduzir conteúdos escolhidos pelo usuário e com a API Google Gemini quando o usuário fornece sua própria chave. Esses serviços possuem políticas de privacidade próprias.

Compartilhamento

O desenvolvedor não vende dados pessoais. Informações são enviadas a serviços externos somente quando necessário para executar uma função solicitada pelo usuário.

Controle do usuário

O usuário pode remover o histórico e os dados locais apagando-os no aplicativo ou desinstalando o ShadowingAI.
